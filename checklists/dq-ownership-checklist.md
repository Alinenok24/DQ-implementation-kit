# DQ Ownership Checklist

Пройдите этот чеклист перед тем, как включать DQ-проверку в регулярный production-контур.

## 1. Rule Ownership

- [ ] У проверки есть владелец.
- [ ] Владелец понимает бизнес-смысл правила.
- [ ] Определено, кто согласует изменение логики.
- [ ] Определено, кто может отключить проверку.

## 2. Severity

- [ ] Severity выбран явно: Critical / Warning / Info.
- [ ] Critical checks блокируют выпуск данных или расчет.
- [ ] Warning checks отправляют alert, но не блокируют pipeline.
- [ ] Info checks используются только для мониторинга.
- [ ] Severity согласован с владельцем домена.

## 3. Reaction Model

- [ ] Определено, кто реагирует на падение.
- [ ] Определен SLA реакции.
- [ ] Определен канал алерта.
- [ ] Определено, когда создается incident.
- [ ] Есть инструкция, что делать при повторяющемся падении.

## 4. Pipeline Behavior

- [ ] Понятно, блокирует ли check pipeline.
- [ ] Понятно, на каком шаге pipeline запускается проверка.
- [ ] Понятно, можно ли rerun только проверки.
- [ ] Понятно, можно ли rerun расчет после исправления данных.
- [ ] Есть правила временного waiver / override.

## 5. Debuggability

- [ ] Check возвращает failed rows sample.
- [ ] Sample содержит business key.
- [ ] Sample содержит failed condition.
- [ ] Logs доступны из run history.
- [ ] Есть ссылка на артефакты запуска.
- [ ] Root cause можно начать искать без ручного SQL с нуля.

## 6. Observability

- [ ] Результаты проверок попадают в общий обзор.
- [ ] Есть история запусков.
- [ ] Видна динамика failures по времени.
- [ ] Видны пропуски запусков.
- [ ] Есть отдельное представление для Critical checks.

## 7. Maintenance

- [ ] Проверка имеет версию или историю изменений.
- [ ] Известно, какие таблицы и поля она использует.
- [ ] Есть тестовые данные или тестовый сценарий.
- [ ] Есть владелец удаления устаревших проверок.
- [ ] Проверка переиспользуется через шаблон, если она типовая.

## Ready For Production

Проверка готова к production, если на все ключевые вопросы есть ответ:

- кто владеет;
- где запускается;
- что делает при падении;
- кому сигналит;
- какие строки возвращает;
- где хранит историю.
